# SMB Hub

**A playful, clickable exploration of a simpler security setup experience.**

This personal prototype tells one design story in three steps: the original experience, a more expressive idea, and a quieter final direction. It is a place to explore the interface and interactions, not a live security service.

## The story

| Step | What to explore |
| --- | --- |
| **Before** | A dense setup experience that asks too much of a new user. |
| **Ideal** | A more visual, playful direction for the same journey. |
| **After** | A simpler onboarding flow that starts with clear empty states and a first device. |

Open the app at `/` to choose a step, or jump to `/prototype-1/dashboard`, `/prototype-2/ideal`, or `/prototype-2/final/summary` when running it locally.

## Run it locally

Requires a current Node.js installation.

```bash
npm install
npm run dev
```

Then open [http://localhost:3000](http://localhost:3000). The app includes a launcher, interactive demo flows, and a simulated Windows installer step. Prototype state and content are local demo data.

Built with Next.js, React, TypeScript, Tailwind CSS, and a few visual libraries for charts and interactive canvases.
